# Prototype ระบบตรวจสอบวุฒิที่โรงเรียนส่งกลับ

เว็บสาธิตสำหรับนำเสนอขั้นตอนรับเอกสาร อ่านผลด้วย AI ส่งเคสเข้าคิวเจ้าหน้าที่ และแสดงประวัติการทำงาน **ทุกข้อมูลเป็นข้อมูลสมมติ** การกดประมวลผลและยืนยันผลจำลองในเบราว์เซอร์ ไม่มีการเรียก Gemini, SCMS หรือ backend และไม่มีการส่งไฟล์ที่เลือกไปยังเซิร์ฟเวอร์

## ทดลองบนเครื่อง

ต้องมี Node.js 22 ขึ้นไป:

```bash
npm ci
npm run dev:web
```

เปิด URL ที่ Vite แสดง ปกติคือ `http://localhost:5173` หน้าหลักเริ่มจากรายการชุดเอกสารตัวอย่าง 6 ชุด การ์ดด้านบนแบ่งเป็น **ผ่านอัตโนมัติ / รอเจ้าหน้าที่ตรวจ / ข้อมูลขัดแย้ง / ส่งต่อกรณีร้ายแรง / ดำเนินการเสร็จแล้ว** กดการ์ดแล้วจะเห็นรายชื่อนักศึกษาจากชุดเอกสารในหมวดนั้น กด **เริ่มรอบประมวลผล** เพื่อแสดง log และผลลัพธ์จำลองใหม่ หรือเลือกไฟล์เพื่อใช้ *ชื่อไฟล์* ในรอบสาธิต โดยเบราว์เซอร์ไม่อ่านเนื้อหาไฟล์

การยืนยันเคสและการตั้งค่าจะเก็บใน `localStorage` ของเบราว์เซอร์นั้นเท่านั้น หากต้องเริ่มการสาธิตใหม่ ให้กด **ตั้งค่า → SCMS & จัดเก็บ → เริ่มข้อมูลสาธิตใหม่**

## Deploy บน Netlify

เชื่อม repository นี้กับ Netlify แล้วให้ Netlify อ่าน [netlify.toml](netlify.toml) ที่ root ซึ่งตั้งค่าไว้ดังนี้:

- Build command: `npm run build`
- Publish directory: `apps/web/dist`
- Node.js: 22

ไม่ต้องตั้ง environment variable, database หรือ backend สำหรับ prototype นี้ สามารถ build ในเครื่องด้วย `npm run build` และตรวจโค้ดด้วย `npm run lint`

## โครงสร้าง

```text
apps/web/             เว็บไซต์ React + TypeScript + Vite ที่ deploy บน Netlify
apps/api/             Python API และ pipeline สำหรับระบบจริงในอนาคต (prototype ไม่เรียกใช้)
legacy/desktop/      โค้ดเดสก์ท็อปเดิม เก็บไว้เป็นข้อมูลอ้างอิง
data/                 ข้อมูลทดสอบของ backend ไม่ถูกนำเข้าเว็บ
```

ข้อจำกัดของ prototype: ข้อมูล AI, ลายมือชื่อ, เอกสารจำลอง และ Audit Trail ไม่ใช่ผลตรวจจริง การเปิดเว็บจากอุปกรณ์คนละเครื่องจะมีสถานะและข้อมูลที่บันทึกแยกกัน

## รูปแบบหน้าจอ

ธีมหลักเป็นขาวชมพูตามโทน SPU โดยใช้สีชมพูสำหรับปุ่มและส่วนที่เลือก สีเขียว/เหลือง/แดงยังใช้เฉพาะสถานะเพื่อให้แยกผลตรวจได้ง่าย หน้าหลักแสดงการ์ดหมวดหมู่แบบ compact แล้วเปิดรายชื่อนักศึกษาเมื่อเลือกหมวด หน้าประมวลผลเรียงจากเตรียมไฟล์ สถานะ ลำดับงาน ผลลัพธ์ และเหตุการณ์ล่าสุด รองรับจอมือถือด้วยเมนูแนวนอนและการจัดคอลัมน์ใหม่
